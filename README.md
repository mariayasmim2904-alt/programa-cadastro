📚 Cadastro de Leitor em Ruby

📌 Sobre o projeto

Este projeto foi desenvolvido em Ruby como um exercício de programação básica.

O programa solicita ao usuário seu nome, sobrenome e idade e, ao final, apresenta essas informações em uma única frase.

🎯 Objetivo

Praticar conceitos básicos da linguagem Ruby, como:

- Entrada de dados com "gets"
- Remoção de caracteres com "chomp"
- Variáveis
- Interpolação de strings
- Saída de dados com "puts"

💻 Funcionamento

Ao executar o programa, o usuário deverá informar:

1. Nome
2. Sobrenome
3. Idade

Depois, o programa exibirá os dados em uma única frase.

Exemplo

Digite seu nome:
Maria

Digite seu sobrenome:
Oliveira

Digite sua idade:
20

Olá, Maria Oliveira! Você tem 20 anos.

🛠️ Tecnologias utilizadas

- Ruby

▶️ Como executar

Com o Ruby instalado, execute no terminal:

ruby cadastro.rb
